# SalesVision Analytics

Interactive Sales Performance Dashboard built for the Web Development for Data Dissemination project.

The project includes index.html, styles.css, app.js, sales_data.csv and technical_report.docx.

Run locally using Visual Studio Code Live Server. Do not open index.html with file:// because the browser may block loading the CSV.

GitHub Pages: open Settings → Pages, choose Deploy from a branch, select main and /(root), then save.

Dataset note: the 72 transactions are simulated teaching data for 2025, not real company records. Currency is EGP. Revenue = quantity sold × unit price. Profit = revenue − cost.
